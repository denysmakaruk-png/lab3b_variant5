Лабораторна робота №3b — Сортування даних

Виконав: Макарук Денис  
Варіант: 5  

Завдання варіанту:
1. Counting sort за полем: Тип повідомлення (Message type).
2. Radix sort за полем: ID користувача (User ID).
3. Comparison sort: Реалізовано алгоритм QuickSort із середньою складністю O(n log n).
4. Провести порівняння швидкості на однакових наборах даних (в пам'яті) для ізольованих полів та комбінацій.

Аналіз складності алгоритмів:
Counting Sort: Має часову складність O(n + k), де k — максимальне значення типу повідомлення. Працює за лінійний час.
Radix Sort: Має часову складність O(d * (n + k)), де d — кількість розрядів у максимальному ID, k = 10 (десяткова система).
QuickSort: Має складність O(n log n) в середньому.

Результати бенчмаркінгу (теоретичні висновки):
На малих масивах різниця між алгоритмами є мінімальною.
На великих обсягах даних лінійні алгоритми сортування (Counting та Radix) демонструють значну перевагу над QuickSort, оскільки вони не виконують операцій порівняння елементів між собою.
Завдяки стабільності реалізованих Counting та Radix sort, комбіноване сортування (спочатку Radix за ID, потім Counting за типом) дає повністю ідентичний результат порівняно з комбінованим QuickSort, але працює швидше на великих масивах.
